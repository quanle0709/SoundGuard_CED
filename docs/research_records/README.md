# Historical Research Records

This directory contains retained reports from earlier SoundGuard/HearSafe evaluation stages. They are historical evidence, not instructions for the current repository layout.

- [`SOUNDGUARD_BENCHMARK_AUDIT_3_LAYER.md`](SOUNDGUARD_BENCHMARK_AUDIT_3_LAYER.md) records the three-layer benchmark audit.
- [`SOUNDGUARD_LAYER2_COMPUTER_ONLY_FINAL.md`](SOUNDGUARD_LAYER2_COMPUTER_ONLY_FINAL.md) records the Layer 2 computer-only evaluation.

The reports were moved here without changing their contents. Their original root paths remain visible in frozen manifests and historical status records, which correctly describe the repository at the time of those experiments.
